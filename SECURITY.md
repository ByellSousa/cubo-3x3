# Seguranca

## Estado de suporte

Ainda nao existe uma versao publica suportada. Os candidatos RC sao builds de
desenvolvimento e nao devem ser tratados como releases publicadas.

## Relato responsavel

Nao publique detalhes exploraveis, backups, bancos, credenciais ou dados de
usuarios em uma issue aberta. Quando o repositorio publico existir, use o canal
privado de advisories de seguranca do GitHub. O endereco definitivo de contato
sera registrado antes da primeira publicacao; nenhum contato foi inventado
neste documento.

Inclua no relato, sem dados pessoais:

- versao/commit afetado;
- passos minimos de reproducao;
- impacto observado;
- logs sanitizados;
- sugestao de correcao, quando houver.

## Dados que nunca devem acompanhar um relato publico

- chave ou senha de assinatura;
- `.3x3backup`, banco Room ou preferencias DataStore reais;
- tempos, comentarios ou embaralhamentos associados a uma pessoa;
- identificadores de aparelho e caminhos locais completos;
- APKs ou capturas de aplicativos usados como referencia.
